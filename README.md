# Clinical Trial Analysis: Fluvir™ Efficacy Study
![image alt](
https://github.com/Maximus-247/A-Randomized-Controlled-Trial/blob/83fc512781f49b5ee4977eb5b3f0f09a965f7e31/Screenshot%202025-04-30%20223210.png)
This project analyzes a randomized, placebo-controlled clinical trial to assess the efficacy of Fluvir™, a novel antiviral treatment for seasonal influenza.

## Overview
The analysis includes logistic regression to model recovery outcomes, odds ratio estimation, predicted probabilities, and visualizations such as forest plots and ROC curves. Results show that Fluvir™ significantly improves the odds of recovery.

## Methods
- Logistic regression to estimate treatment effect while adjusting for age, gender, and comorbidities.
- Calculation of odds ratios and confidence intervals.
- Visualization of model results using forest plots and boxplots.

## Tools
- **R Programming Language**
- **tidyverse**, **broom**, **pROC**

## Key Findings
- Fluvir™ significantly increases recovery odds.
- Age and comorbidities reduce the chances of recovery.
- Predicted recovery probabilities were higher in the Fluvir™ group.
